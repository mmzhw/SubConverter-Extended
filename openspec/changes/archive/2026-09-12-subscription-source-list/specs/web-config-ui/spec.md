## MODIFIED Requirements

### Requirement: 可视化组装订阅 URL

界面 SHALL 提供表单控件让用户选择目标格式、输入订阅源地址并勾选常用转换选项，实时生成对应的 subconverter 订阅请求 URL 并展示给用户。

订阅源地址控件 SHALL 是多行文本域，**一行一个订阅源**。生成链接时，界面 SHALL 把各行
用 `|` 连接后写入 `url=` 参数，因为 `|` 是 subconverter 表示多个订阅源的分隔符，而
逗号在 `url=` 的子语法中用于分隔单个订阅源的**前缀选项**与源 URL
（如 `interval:21600,https://example.com/sub`），MUST NOT 被当作多源分隔符。

从一个已生成的链接导入时，界面 SHALL 把 `url=` 中的 `|` 还原为换行，使"导入 → 再生成"
得到同一个 `url=` 值。

界面 SHALL 逐行校验订阅源，并在某一行出现"逗号紧跟 `http://` 或 `https://`"这种
多源误用形态时给出明确提示（指出应一行一个），而不是静默生成一个指向无效地址的链接。

#### Scenario: 基本组装

- **WHEN** 用户选择目标格式 clash 并输入订阅源地址
- **THEN** 界面生成的 URL 包含 `target=clash` 与经过 URL 编码的 `url` 参数

#### Scenario: 实时更新

- **WHEN** 用户修改任一表单控件
- **THEN** 展示的 URL 立即更新，无需手动提交

#### Scenario: 参数编码

- **WHEN** 订阅源地址包含 `&`、`=` 等特殊字符
- **THEN** 生成的 URL 中 url 参数经过正确的百分号编码，可直接被服务端解析

#### Scenario: 多个订阅源用竖线连接

- **WHEN** 用户在文本域里分两行输入两个订阅源地址
- **THEN** 生成的链接中 `url` 参数的解码值是 `源1|源2`，且不含换行

#### Scenario: 导入含多个订阅源的链接后往返一致

- **WHEN** 用户导入一个 `url=` 为 `源1|源2` 的链接
- **THEN** 文本域显示为两行，且不再改动直接生成时 `url=` 仍为 `源1|源2`

#### Scenario: 空行不产生空订阅源

- **WHEN** 文本域内容为「源1、空行、源2」，且各行首尾有空白
- **THEN** 生成的 `url=` 为 `源1|源2`，不出现 `||` 或空段

#### Scenario: 逗号分隔多源时给出提示

- **WHEN** 某一行内容为 `https://a.example/sub,https://b.example/sub`
- **THEN** 界面显示提示，说明检测到用逗号分隔多个订阅源、应一行一个；
  该提示 MUST NOT 把这一行静默拆成两个源
