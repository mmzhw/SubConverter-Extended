## Purpose

前端可视化配置界面是一个浏览器单页应用，让用户通过表单方式组装 subconverter 订阅 URL、导入现有链接、保存预设并复制分享，无需手工拼接查询参数。

## ADDED Requirements

### Requirement: 可视化组装订阅 URL

界面 SHALL 提供表单控件让用户选择目标格式、输入订阅源地址并勾选常用转换选项，实时生成对应的 subconverter 订阅请求 URL 并展示给用户。

#### Scenario: 基本组装

- **WHEN** 用户选择目标格式 clash 并输入订阅源地址
- **THEN** 界面生成的 URL 包含 `target=clash` 与经过 URL 编码的 `url` 参数

#### Scenario: 实时更新

- **WHEN** 用户修改任一表单控件
- **THEN** 展示的 URL 立即更新，无需手动提交

#### Scenario: 参数编码

- **WHEN** 订阅源地址包含 `&`、`=` 等特殊字符
- **THEN** 生成的 URL 中 url 参数经过正确的百分号编码，可直接被服务端解析

### Requirement: 导入现有订阅链接解析

界面 SHALL 支持粘贴一条已有的 subconverter 订阅链接，解析其中的查询参数并回填到表单；无法解析时 SHALL 给出明确错误提示且不破坏当前表单状态。

#### Scenario: 成功导入

- **WHEN** 用户粘贴一条包含 target、url 与多个选项参数的订阅链接
- **THEN** 表单控件被解析出的参数值回填

#### Scenario: 无效链接

- **WHEN** 用户粘贴的内容不是合法的 subconverter 订阅链接
- **THEN** 界面显示错误提示，表单保持导入前状态

### Requirement: 预设保存与复用

界面 SHALL 允许用户将当前表单配置保存为命名预设并持久化到浏览器本地存储，支持加载与删除预设；浏览器本地存储不可用时 SHALL 明确提示用户。

#### Scenario: 保存并加载

- **WHEN** 用户保存当前配置为预设，并在新会话中加载该预设
- **THEN** 表单恢复为保存时的状态（含目标格式、订阅源与选项）

#### Scenario: 存储不可用

- **WHEN** 浏览器禁用本地存储
- **THEN** 界面提示预设无法保存，其余功能不受影响

### Requirement: 一键复制与二维码

界面 SHALL 提供一键复制按钮把当前 URL 复制到剪贴板，并展示对应二维码；二维码内容 SHALL 与展示的 URL 完全一致。

#### Scenario: 复制

- **WHEN** 用户点击复制按钮
- **THEN** 当前 URL 被复制到剪贴板并显示复制成功反馈

#### Scenario: 二维码

- **WHEN** 界面展示当前 URL
- **THEN** 同时渲染内容为该 URL 的二维码，可用于手机扫码导入

### Requirement: 界面语言

界面文本 SHALL 提供中文与英文，默认跟随浏览器语言偏好，并允许用户手动切换。

#### Scenario: 语言跟随

- **WHEN** 用户浏览器语言为中文
- **THEN** 界面默认显示中文文本

#### Scenario: 手动切换

- **WHEN** 用户点击语言切换按钮
- **THEN** 界面文本立即切换为另一种语言

### Requirement: 后端地址可配置

组装出的 URL 默认 SHALL 使用相对路径（同源部署时直接可用）；界面 SHALL 提供高级选项允许用户指定自定义 subconverter 后端地址。

#### Scenario: 同源部署

- **WHEN** 用户未指定自定义后端地址
- **THEN** 生成的 URL 使用相对路径，可直接在当前部署中打开

#### Scenario: 自定义后端

- **WHEN** 用户填写自定义后端地址
- **THEN** 生成的 URL 以该地址为前缀

### Requirement: 视口支持

界面 SHALL 同时支持桌面端与移动端视口：桌面端（≥1024px）采用两栏布局（左侧表单、右侧结果预览）；移动端采用单栏布局，复制与二维码操作 SHALL 通过固定底部操作区保持便捷可达，触控目标不小于 44×44px，页面不出现横向滚动。

#### Scenario: 桌面端布局

- **WHEN** 用户在视口宽度 ≥1024px 的浏览器中打开界面
- **THEN** 界面以两栏布局显示，表单与结果预览同时可见

#### Scenario: 移动端布局

- **WHEN** 用户在窄视口（如 375px 宽）的移动设备上打开界面
- **THEN** 界面以单栏布局显示，无横向滚动，复制与二维码操作可通过固定底部操作区完成
